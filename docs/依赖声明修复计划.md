# pi-to-chrome 依赖声明修复计划

## 背景与目标

- pi 0.99.0 起在加载扩展包时检查 package.json：宿主提供的模块出现在 `dependencies` 字段即输出警告
- 本次启动的警告来自 pi-to-chrome：`@sinclair/typebox` 被写进了 dependencies
- 目标：
	- manifest 对齐官方规范
	- 重启 pi 后零警告
	- 功能零回归

## 官方判定标准

来源为 pi 的 `docs/packages.md` 与 `dist/core/resource-loader.js` 里的检测实现：

- 检测逻辑只扫 manifest 的 `dependencies` 字段，命中下列名单即告警：
	- `@earendil-works/pi-agent-core`
	- `@earendil-works/pi-ai`
	- `@earendil-works/pi-coding-agent`
	- `@earendil-works/pi-tui`
	- `@mariozechner/pi-agent-core`
	- `@mariozechner/pi-ai`
	- `@mariozechner/pi-coding-agent`
	- `@mariozechner/pi-tui`
	- `@sinclair/typebox`
	- `typebox`
- 声明要求：上述模块必须放 `peerDependencies` 且范围写 `"*"`，不得放 `dependencies`
- 本地类型检查需要物理副本时放 `devDependencies`（官方允许）

## package.json 改动

改前：

```json
  "dependencies": {
    "@sinclair/typebox": "^0.34.49",
    "puppeteer-core": "^24.0.0"
  },
  "peerDependencies": {
    "@earendil-works/pi-coding-agent": "*"
  },
  "devDependencies": {
    "typescript": "^6.0.3"
  }
```

改后：

```json
  "dependencies": {
    "puppeteer-core": "^24.0.0"
  },
  "peerDependencies": {
    "@earendil-works/pi-coding-agent": "*",
    "@sinclair/typebox": "*"
  },
  "devDependencies": {
    "@sinclair/typebox": "^0.34.49",
    "typescript": "^6.0.3"
  }
```

改动要点说明：

- dependencies 删掉 `@sinclair/typebox`，这是消除警告的关键一步
- peerDependencies 用 `"*"` 范围声明，与宿主供应关系对齐
- devDependencies 保留带版本号的条目，供本地 tsc 类型检查使用

## 风险与说明

- 全程不改任何 .ts 源码，运行时行为零变化
- npm 7 及以上会自动安装根项目自己的 peerDependencies，npm install 后 node_modules 里可能仍出现 typebox 物理副本；这不影响结果，因为警告检测只看 manifest 的 dependencies 字段，且 pi 运行时优先走虚拟模块映射
- 改完后 manifest 形态即官方推荐形态（peer 声明 `"*"` 加 devDependencies 物理副本），与 pi-in-zellij 修复后的形态一致
- 预计工作量：约 10 分钟（含验证）
